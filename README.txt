=======================
Magnetospheric Models
=======================

Hydrogen lines
----------------
 Balmer series:   2-3 to 2-7
 Paschen series:  3-4 to 3-16
 Brackett series: 4-5 to 4-16

Calcium II lines
----------------
 CaII H: 1-4
 CaII K: 1-5

 Infrared triplet lines(IRT)
 
 CaII 8498.02: 2-5
 CaII 8542.09: 3-5
 CaII 8662.14: 2-4

Parameters
----------------
 Magnetospheric parameters are described in summary_all
 Model stellar parameters are described in model_stellar_parameters

Note about geometries: 

 All the lines have the first 6 (basic) geometries. 
 Lines: Ca: 15,25,35 and H: 2-3,2-4,2-5,3-5,3-6,3-7,4-7 have a more detailed grid in geometries, the index of the maximun possible geometry for each line is detailed in: line_geo_extension

Notes about Ca abundances

 All calcium lines have solar abundance.
 Lines Ca:15,25,35 have a grid in abundances from 1 to 0.01 solar abundances. For M3 star all Ca lines have all abundances.
 Detailed ID of each abundance in ca_abundance

File names
--------------
All the profile files are identified with the parameters ID used in the model.

Hydrogen lines: prof.line.geo.mdot.temp.incl.0

Calcium lines:  prof.line.abundance.geo.mdot.temp.incl.0
